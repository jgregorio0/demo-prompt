# Project Briefing: demo-prompt

This project provides a structured framework for AI agents.
It includes skills and templates to standardize common tasks.

Objectives:
- Simplify agent onboarding with clear instructions.
- Standardize commit messages and development workflows.
- Provide reusable prompts for various development phases.

Key Features:
- Custom skills in `.agents/skills`.
- Standardized documentation structure.
- Conventional commit guidelines.
